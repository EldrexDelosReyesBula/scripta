# Marginalia — Scripta font family

A first working build based on the supplied Scripta/Marginalia brief.

**Faces**
- Marginalia Mono Regular / Medium
- Marginalia Serif Regular / Medium / Italic / Medium Italic

**Implemented**
- Mono metrics widened about 5% for screen readability.
- Mono punctuation receives a slight visual emphasis.
- Serif Q and R receive subtle custom proportion adjustments.
- Family/style metadata is renamed to Marginalia.
- Broad Unicode coverage is inherited from the Noto bases.

**Important**
This is a functional first build, not a final hand-drawn 450–500-glyph production typeface. A professional final version should redraw and proof every glyph, kerning pair, punctuation mark, and weight master individually, and then build a true variable font.
